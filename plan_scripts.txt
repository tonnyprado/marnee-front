 Plan: Sistema de Scripts y Sincronización para Marnee

 Resumen

 Crear una nueva sección "Scripts" en Marnee que:
 1. Liste todos los scripts generados automáticamente desde el chat
 2. Permita relacionar scripts con posts del calendario
 3. Mantenga sincronización completa entre Chat → Scripts → Calendario

 ---
 Arquitectura Propuesta

 Chat (usuario pide script)
     ↓
 Backend detecta script_generation
     ↓
 Extrae hook/body/cta de respuesta → Guarda en tabla "scripts"
     ↓
 Respuesta incluye { savedScript: { id, title } }
     ↓
 Frontend muestra notificación "Script saved!"
     ↓
 Usuario puede ver en /app/scripts
     ↓
 Vincular script a post del calendario

 FASE 7: Auto-vinculación Inteligente (AI Matching)

 Lógica de auto-vinculación

 Modificar: /app/routers/marnee.py

 Cuando se genera un calendario, Marnee debe:
 1. Buscar scripts existentes del founder
 2. Analizar contenido de cada script vs. cada post
 3. Si hay match (>70% relevancia), auto-vincular

 async def auto_link_scripts_to_calendar(founder_id, calendar_posts):
     scripts = await get_unlinked_scripts(founder_id)
     for post in calendar_posts:
         best_match = find_best_script_match(post, scripts)
         if best_match and best_match.score > 0.7:
             await link_script_to_post(best_match.script_id, post.id)

 Criterios de matching

 - Coincidencia de plataforma
 - Similitud de tema/pillar
 - Keywords comunes entre hook del script y título/hook del post
 - Content type compatible

 Verificación

 Tests manuales

 1. Chat → Script auto-guardado:
   - Pedir a Marnee "Write a script for my next TikTok"
   - Verificar notificación "Script saved!"
   - Ir a /app/scripts y ver el nuevo script
 2. Gestión de scripts:
   - Crear script manual desde la página
   - Editar script existente
   - Eliminar script
   - Filtrar por status
 3. Vincular a calendario:
   - Abrir un post en el calendario
   - Ir a la sección "Script"
   - Vincular script existente
   - Verificar que el script muestra "Linked to post"
 4. Sincronización:
   - Generar calendario desde chat
   - Verificar que posts se crean basados en conversación
   - Vincular scripts relevantes a posts

 ---
 Decisiones Tomadas

 1. Content Insights: Ya está incluido en el Dashboard existente (no crear sección separada)
 2. Auto-vinculación: Sí, Marnee auto-vinculará scripts a posts usando AI matching (>70% relevancia)
 3. Detección de scripts: Usar AMBOS métodos (intención del usuario + estructura Hook/Body/CTA)
