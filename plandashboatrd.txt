 Plan: Grafo de Neuronas "Marnee Brain" para Dashboard

 Resumen

 Agregar una nueva sección al Dashboard que muestre un grafo interactivo tipo neuronas con todo el conocimiento que Marnee tiene del
 usuario, derivado de su perfil, test de negocio, estrategia y conversaciones.

 Dependencia a Instalar

 npm install react-force-graph-2d

 Archivos a Crear

 1. Constantes del Grafo

 Archivo: src/constants/graphConstants.js
 - Colores por categoría de nodo (expertise=verde, valores=rosa, pillars=teal, etc.)
 - Tamaños de nodos por importancia
 - Usuario central en morado Marnee (#40086d)

 2. Extractor de Temas de Conversaciones

 Archivo: src/utils/topicExtractor.js
 - Función extractTopicsFromConversations(conversations)
 - Usa patrones regex para identificar frases clave de mensajes del usuario
 - Retorna top 10 temas más mencionados con conteo

 3. Transformador de Datos a Grafo

 Archivo: src/utils/graphTransformer.js
 - Función transformToGraph({ founderProfile, businessTest, strategy, conversationTopics })
 - Crea nodo central del usuario
 - Mapea cada fuente de datos a nodos conectados al usuario:
   - topicsConfidentTeaching[] → nodos expertise (verde)
   - topicsPeopleAskAbout[] → nodos audience_interest (azul)
   - personalValues[] → nodos value (rosa)
   - otherPassions[] → nodos passion (naranja)
   - associatedKeywords[] → nodos business_keyword (indigo)
   - contentPillars[] → nodos content_pillar (teal)
   - nicheKeywords[] → nodos niche_keyword (cyan)
   - Temas de conversaciones → nodos conversation_topic (gris)

 4. Hook de Datos

 Archivo: src/hooks/useKnowledgeGraph.js
 - Carga datos en paralelo de 4 APIs existentes:
   - api.getMeFounder()
   - api.getBusinessTestMe()
   - getStrategyByFounder(founderId)
   - api.getConversations() + api.getConversation(id) para cada una
 - Transforma datos usando graphTransformer
 - Retorna { graph, loading, error, dataCompleteness, refresh }
